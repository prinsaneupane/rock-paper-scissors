# rock-paper-scissors
simple web game

## Features
Score Tracking
Interactive
Dynamic UI

## How to Play
1. Select your choice by clicking the rock, paper, scissors icon.
2. The computer will automatically generate a choice.
3. The winner  is instantly declared, and the scoreboard is updated. 
 
## Tech Stack
HTML5
CSS3
Tailwind CSS
JavaScript
